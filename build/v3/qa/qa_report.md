# تقرير مراجعة الجودة (qa) — v3

**المراجع:** دور qa-reviewer نُفّذ داخل الجلسة الرئيسية (claude-sonnet-5-5) لأن تشغيل الوكلاء كعمليات مستقلة رُفض من مصنّف الأمان (انظر build_log.txt).

## التغطية
- **قراءة يدوية كاملة** لكل صف جديد أو معاد كتابته عدا practical-grounded: 1554 صفًا في 32 دفعة (build/v3/qa/in/qa_NNN.jsonl، 50 صفًا للدفعة) — dialect-east/hijaz/nejd/north/south وpractical-messages.
- **فحص آلي على كل الصفوف** (validate عند الإنشاء ثم check_sft.py): الصيغة، المؤشرات المعجمية، الفصحى، الطول، الحسابيات، أنماط اختراع السياسات، التكرار، التقاطع.
- **practical-grounded (339 صفًا):** فحص آلي فقط + مراجعة عند الكتابة: إجابة text_answerable مقتبسة حرفيًا من الفقرة (تُتحقق آليًا)، ورفض text_unanswerable يستند إلى النص، والفقرات ≤ 3 استعمالات، ولا تشابه مع v2/dialect_test.
